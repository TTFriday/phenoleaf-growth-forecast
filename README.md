# phenoleaf-growth-forecast

Short-horizon forecasting of visible leaf count and projected rosette area of
*Arabidopsis thaliana* from time-lapse images, with a leakage-controlled
evaluation protocol.

The code forecasts both traits 24, 48 and 72 h ahead from the preceding 48 h of a
plant's image series and compares:

- simple baselines (persistence, Theil–Sen trend, damped trend) and gradient boosting;
- neural forecasters (direct MLP, GRU, trend-residual and reliability-gated trend-residual models);
- forecasters with and without image embeddings (task-specific features of the
  measurement network and generic ImageNet ResNet-18 features).

Trait histories come either from the leaf annotations (Protocol A) or from a
ResNet-18 that measures leaf count and area in every frame (Protocol B). The
measurements of the training plants are cross-fitted (five folds), so the
measurement network never measures a plant it was trained on.

## Data

The experiments use the PhenoLeaf-TS dataset (17,082 RGB frames, 318 plants,
21 genotypes). The dataset is not redistributed here; download it from its
authors (see the PhenoLeaf-TS project page and Hugging Face dataset
`rick77a/PhenoLeaf_TS`) and respect its license. After unpacking, point the
code to the folder that contains `01_raw_dataset`, `02_leaf_labels` and
`leaves_unique_colours.xlsx`:

```bash
export PHENOLEAF_ROOT=/path/to/PhenoLeaf-TS_DS
```

If the variable is not set, `data/PhenoLeaf-TS_DS` inside the repository is used.

## Installation

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Tested with Python 3.10, PyTorch 2.6 (CUDA 12.4) and scikit-learn 1.6 on one
NVIDIA RTX 3090. Measurement training and feature extraction require a CUDA GPU.

## Running the pipeline

```bash
python scripts/01_extract_phenotypes.py        # leaf count and area per frame from the masks
python scripts/02_build_forecast_samples.py    # rolling-origin samples (48 h history, 24/48/72 h targets)
python scripts/03_train_measurement_models.py  # ResNet-18 measurement, 5-fold cross-fitting (~8 min)
python scripts/04_extract_imagenet_embeddings.py
python scripts/05_run_forecasters.py           # all forecasters, 5 seeds, both protocols (~30 min)
python scripts/06_evaluate.py                  # MAE, plant-level bootstrap CIs, paired tests
python scripts/07_conformal.py                 # split-conformal prediction intervals
python scripts/08_figures.py                   # result figures
```

All outputs are written to `outputs/`. The plant-level partition used in the
study (190 training, 47 validation, 37 calibration and 44 test plants, stratified
by genotype) is fixed in `splits/plant_split.json`.

## Repository layout

```
leafcast/          library code
  config.py        paths and constants
  io.py            dataset indexing, mask-derived phenotypes
  measure.py       ResNet-18 measurement model with test-time augmentation
  data.py          assembly of forecasting tensors and image features
  features.py      history descriptors, Theil–Sen trend, reliability indicators
  models.py        forecasters and training loop (incl. noise injection)
  stats.py         plant-level bootstrap, paired tests, Holm adjustment
scripts/           numbered pipeline steps
splits/            plant-level partition
results/           summary results produced by the pipeline
```

## Results included

`results/` holds the summary files produced by the pipeline for the reported run:
`metrics.csv` (test MAE per model, protocol, horizon and noise level with 95%
plant-level bootstrap intervals), `comparisons.csv` (paired comparisons with
bootstrap, Wilcoxon and Holm-adjusted p-values), `conformal.csv` and
`conformal_conditional.csv` (interval coverage and width), the measurement accuracy
per partition and the training logs. Per-frame phenotypes and model weights are
not included because they are derived from the dataset annotations; they are
regenerated by the scripts above.

Main findings on the 44 test plants (mean over horizons):

| History | Persistence | Theil–Sen trend | GRU | Gradient boosting |
|---|---|---|---|---|
| Annotation-derived, leaf count (leaves) | 1.35 | 1.59 | 0.80 | 0.81 |
| Image-measured, leaf count (leaves) | 1.57 | 1.12 | 0.94 | 0.95 |
| Annotation-derived, area (pp) | 3.22 | 1.36 | 0.77 | 0.77 |
| Image-measured, area (pp) | 3.29 | 1.49 | 0.84 | 0.85 |

Adding image embeddings did not improve any forecaster, and training with
injected measurement noise made the forecasters robust to degraded measurements.
